# 樱花守卫战

二次元风格的魔法少女塔防小游戏，单个 `index.html`，用浏览器直接打开就能玩（手机也可以）。

## 玩法

- 魔物沿小路走向樱之水晶，漏掉一只就扣生命，生命归零即失败；撑过 15 波获胜。
- 点右侧角色卡（或按 1–4），再点草地召唤魔法少女；手机上点一下预览、再点一下确认。
- 击败魔物得金币，用来召唤新角色或升级（最高 Lv.3，满级会长出翅膀）；出售返还 70%。
- 两波之间自动倒计时 20 秒，提前开战可拿额外金币。
- 难度：简单 / 普通 / 困难，影响生命、初始金币和魔物血量成长。

| 角色 | 定位 | 特点 |
| --- | --- | --- |
| 小樱 · 樱花射手 | 50 金 | 攻速快，单体输出 |
| 雪奈 · 冰霜法师 | 70 金 | 减速，满级溅射 |
| 焰华 · 爆炎魔女 | 100 金 | 范围爆炸，克制护甲 |
| 雷音 · 雷光巫女 | 120 金 | 连锁闪电，无视护甲 |

魔物：果冻史莱姆、调皮幽灵（快）、南瓜骑士（护甲）、胖胖史莱姆（死后分裂）、暗影魔王（第 5 / 10 / 15 波）。

快捷键：`1–4` 选角色 · `空格` 暂停 · `F` 切换 1×/2×/3× 速度 · `N` 开始下一波 · `U` 升级 · `X` 出售 · `Esc` 取消选择。

## 实现

纯 HTML + Canvas + 原生 JS，无构建步骤、无外部图片，角色和魔物都是代码绘制；音效用 WebAudio 实时合成。字体来自 Google Fonts，离线时自动回退到系统字体。
